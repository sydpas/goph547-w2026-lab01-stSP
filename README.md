Instructor: Brandon Karchewski, Author: Sydney Pasloski, UCID: 30178579
## General overview.
This lab explores the concept of gravity potential and gravity effect at various elevations, and with single and multi point masses.
## How to clone the repository.
Open your preferred terminal on your local device.
Navigate to the directory where the repository files will be stored.
- If you have an SSH key setup on the device, use: git clone git@github.com:sydpas/goph547-w2026-lab01-stSP.git
- If you do not have an SSH key, use: git clone https://github.com/sydpas/goph547-w2026-lab01-stSP.git
- If you have GitHub CLI, use: gh repo clone sydpas/goph547-w2026-lab01-stSP
## How to make a vitural environment.
In the project folder, create the virtual environment (venv) by typing [virtualenv .venv] into terminal without the
brackets. To activate, type [.venv/Scripts/Activate] and to deactivate, simply type [deactivate].
## To run the code...
In each *driver.py* file, simply hit [Run] to see the output of the code.
